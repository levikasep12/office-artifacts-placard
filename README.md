A single original museum placard for an ordinary office object, written as if it were an ancient artifact, generated by a tiny deterministic program: a sticky note, c. 2004, adhesive paper — prayer flag of the Open-Plan era, inscribed "per my last email" in fading ink; donor declined to elaborate.

## Run it

```sh
python3 main.py
```

It writes one line of placard (145 characters) to `/output/entry.txt`. Standard library only, no network, no input files, and the same bytes on every run from any working directory.
